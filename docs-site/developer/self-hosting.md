# Self-Hosting

::: warning Future — not officially supported yet
DocuShark's sync server is open source and can already be run yourself, but there's no polished, supported self-host product yet. The goal is a lean, customizable image — free of DocuShark Cloud's account, billing, and managed features — that gives you full control over your own storage, for a focused, primitive setup. The full setup manual lands here once that's ready.
:::

In the meantime, the sync server's source and its current (unpolished) run instructions live in [`relay/README.md`](https://github.com/JPE-Net-Technologies/docushark/blob/master/relay/README.md) in the repository.

Organizations that need a professionally managed installation instead of the DIY path should reach out directly — that's handled outside of self-hosting.
