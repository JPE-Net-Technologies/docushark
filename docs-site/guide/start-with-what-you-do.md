# Start with what you do

DocuShark does a lot, and you need only the part that fits your work. Pick the path closest to yours; each one is a few steps, in the order you'll need them. New to DocuShark? Read [Start here](./start-here) first; it takes ten minutes.

## Research {#research}

For a thesis, a study or a literature review: your notes, your sources and your figures in one document.

1. **Cite as you write.** Paste a paper's DOI and it becomes a citation, or import your library as BibTeX. A bibliography in APA, MLA, Chicago or Vancouver keeps itself up to date. See [Write → Citations](./write#citations).
2. **Keep the papers with the notes.** Attach PDFs and read them in DocuShark: search them, bookmark pages, cite a paper straight from its PDF, and send a page to the canvas to mark it up. See [Write → Files](./write#files).
3. **Show the method.** Draw the study design or a concept map on a canvas beside your notes ([Draw](./draw)), and write equations, tables and captioned figures in the text ([Write](./write#equations)).
4. **Keep a project in one place.** Give each part its own page, and tag documents by project or theme so search finds them. See [Organize](./organize).
5. **Hand it in.** Export a PDF with a cover page, a table of contents and page numbers. See [Export and import → PDF](./export-import#pdf).

Walk through it end to end: [A research notebook](/tutorials/research-project).

## Engineering {#engineering}

For design docs, architecture and data models: the explanation and the diagram side by side, so neither goes stale.

1. **Write the doc and draw the system together.** Use **Split** to keep both in view, and put a picture of a diagram group in the text where it helps. See [Write → Diagrams in your writing](./write#diagrams).
2. **Draw fast.** Connectors route themselves around shapes; the libraries hold flowchart, UML, ERD and sequence-diagram shapes, plus cloud and technology icons; and `Ctrl+Shift+L` lays a diagram out for you. See [Draw](./draw).
3. **Bring in what you have.** Import Mermaid, draw.io or Excalidraw diagrams as editable shapes. See [Export and import → Import](./export-import#import).
4. **Keep names and versions in one place** with fields, so a rename is one edit. See [Write → Fields](./write#fields).
5. **Review together.** Share the document in your workspace and edit it live. See [Share and collaborate](./share).
6. **Turn up the density** with the Technician or Power layout, and learn the [keyboard shortcuts](./keyboard-shortcuts). See [Make it yours → Layouts](./make-it-yours#layouts).

Walk through it end to end: [A design doc with a diagram](/tutorials/design-doc-with-diagram).

## Personal {#personal}

For notes, plans, lists and the files that go with them, kept private on your own device.

1. **Start without an account.** Documents you make without signing in stay on your device and work offline. Install DocuShark as an app to open it in its own window. See [Start here](./start-here#get-docushark).
2. **Write it down.** Headings, checklists, tables and photos, with formatting as you type. See [Write](./write).
3. **Keep the files together.** Attach the PDF, the spreadsheet or the scan to the document it belongs with. See [Write → Files](./write#files).
4. **Think on a canvas.** Sketch a plan, or brainstorm on the whiteboard's sticky notes; the Caveat font gives shapes a handwritten look. See [Draw](./draw#whiteboard).
5. **Find things later** with collections and tags. See [Organize](./organize#collections-and-tags).
6. **Make it yours,** from the theme to a layout for your phone. See [Make it yours](./make-it-yours).
7. **Keep a backup** of everything on this device in one file. See [Export and import → Back up everything](./export-import#backup).

For ideas, see the [example gallery](/tutorials/examples).

## AI agents {#ai-agents}

For documents an AI agent reads and writes with you, through MCP, the open standard agents use to work with tools.

1. **Connect your agent** in a few minutes: Claude, ChatGPT, Cursor or another MCP client. See [Share and collaborate → Connect an AI agent](./share#connect-an-ai-agent).
2. **Ask for real documents.** An agent can create documents, write and restructure prose, build diagrams, add references and set fields. It writes to your workspace documents, and can read your local ones without changing them.
3. **Work alongside it.** What the agent writes appears in the open document as it writes, like any collaborator's edits. Undo takes back only your own changes, and [version history](./organize#history-and-trash) can take the document back to before.
4. **Give it a head start.** A template with [fields](./write#fields) lets an agent fill in a document from a prompt, and ready-made recipes cover jobs such as an architecture RFC or turning notes into an outline. See [AI agents and recipes](/developer/mcp-agent-recipes).
