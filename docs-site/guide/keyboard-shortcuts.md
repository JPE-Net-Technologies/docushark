# Keyboard Shortcuts

Most things in DocuShark have a shortcut. If you ever forget one, you don't need to memorize a cheat sheet — press `Ctrl+K` (`Cmd+K` on Mac) to open the **command palette** and search for any action by name. It's the fastest way to discover a shortcut while you're using it.

## The ones people learn first

| Action | Shortcut |
|--------|----------|
| Command palette | `Ctrl+K` / `Cmd+K` |
| Save now (DocuShark also saves as you work) | `Ctrl+S` / `Cmd+S` |
| Search your library (Documents home) | `/` or `Ctrl+K` |
| Select tool | `V` |
| Connector tool | `C` |
| Undo / Redo | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Copy / Paste | `Ctrl+C` / `Ctrl+V` |
| Paste without formatting (in a document) | `Ctrl+Shift+V` |
| Delete | `Delete` or `Backspace` |
| Select all | `Ctrl+A` |
| Group / Ungroup | `Ctrl+G` / `Ctrl+Shift+G` |
| Zoom in / out | Ctrl/⌘ + scroll, pinch, or `E` / `Q` |
| Pan | Scroll, two-finger drag, `WASD`, or middle-click + drag |
| Move between the top bar, your text and the canvas | `F6` / `Shift+F6` |

(Use `Cmd` in place of `Ctrl` on macOS.)

In a browser tab, `F6` belongs to the browser. Use the command palette's
**Move focus to the canvas** and **Move focus to the text** instead; the desktop
app and an installed app pass `F6` to DocuShark.
