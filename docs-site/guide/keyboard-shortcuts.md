# Keyboard shortcuts

You don't need to memorize these. Press `Ctrl+K` (`Cmd+K` on a Mac) for the **command palette**, search for any action by name, and it shows the action's shortcut. On a Mac, use `Cmd` wherever this page says `Ctrl`.

## Everywhere {#everywhere}

| Action | Shortcut |
|---|---|
| Command palette | `Ctrl+K` |
| Save now (DocuShark also saves as you go) | `Ctrl+S` |
| Undo / Redo | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Go to Documents | `Ctrl+Shift+O` |
| Write, Split or Canvas, in turn | `Ctrl+Shift+\` |
| Relaxed, Designer, Technician or Power layout | `Ctrl+Shift+1` to `4` |
| Whiteboard (when you aren't typing) | `Ctrl+I` |
| Move between the top bar, your writing and the canvas | `F6` / `Shift+F6` |

In a browser tab, `F6` belongs to the browser: use **Move focus to the canvas** and **Move focus to the text** in the command palette instead. The desktop app and an installed app pass `F6` to DocuShark.

## In your library {#library}

| Action | Shortcut |
|---|---|
| Search | `/` |
| Search tags only | Type `#` and the tag |

## Writing {#writing}

| Action | Shortcut |
|---|---|
| Bold, italic, underline | `Ctrl+B`, `Ctrl+I`, `Ctrl+U` |
| Inline code | `Ctrl+E` |
| Heading 1, 2, 3 / Text (body text) | `Ctrl+Alt+1`, `2`, `3` / `Ctrl+Alt+0` |
| Bulleted / numbered list | `Ctrl+Shift+8` / `Ctrl+Shift+7` |
| Indent / outdent a list item | `Tab` / `Shift+Tab` |
| Insert anything | `/` at the start of a line |
| Cite a source / insert a field | `@` / <code v-pre>{{</code> |
| Paste without formatting | `Ctrl+Shift+V` |
| Find and replace | `Ctrl+F` |

More typing shortcuts, such as `#` for a heading, are in [Write](./write#formatting).

## Drawing {#drawing}

| Action | Shortcut |
|---|---|
| Select, Pan | `V`, `H` |
| Rectangle, Ellipse, Line | `R`, `O`, `L` |
| Connector, Text | `C`, `T` |
| Select all / delete | `Ctrl+A` / `Delete` or `Backspace` |
| Copy / paste | `Ctrl+C` / `Ctrl+V` |
| Group / ungroup | `Ctrl+G` / `Ctrl+Shift+G` |
| Select everything connected | `Ctrl+Shift+A` |
| Lay out the selection, top to bottom | `Ctrl+Shift+L` |
| Nudge the selection | Arrow keys; hold `Shift` for bigger steps |
| Keep proportions while resizing; turn in 15° steps while rotating | Hold `Shift` |
| Finish a label / new line / cancel | `Enter` / `Shift+Enter` / `Escape` |

## Moving around the canvas {#moving-around}

| Action | Shortcut |
|---|---|
| Pan | Scroll, two-finger scroll, middle-click and drag, or `W` `A` `S` `D` |
| Pan sideways with a mouse | `Shift`+scroll |
| Zoom | `Ctrl`+scroll, pinch, or `Q` / `E` |

Every other shortcut, for each tool and modifier key, is in the [full keyboard shortcuts reference](/developer/keyboard-shortcuts-reference).
